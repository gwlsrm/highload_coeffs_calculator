# Highload coefficient calculator

## Описание

Эта утилита позволяет рассчитывать коэффициент "A" коррекции живого времени в SpectraLine для спектров с высокой загрузкой. В таких спектрах присутствуют просчёты из-за случайного суммирования импульсов в анализаторе.

## Использование

- Выполнить несколько (как минимум 2) измерений источника гамма-излучения на одном и том же расстоянии, но с разной загрузкой. Разную загрузку можно получить используя другой источник гамма-излучения (с другим радионуклидом) -- либо более мощный, либо можно поместить его ближе к детектору.
- Значения загрузки (интегральной скорости счёта во всём спектре) и получаемой скорости счёта в выбранном пике полного поглощения 1-го источника нужно занести в таблицу. Значение загрузки можно увидеть в левом нижнем углу в окне спектра в SpectraLine. Значение скорости счёта можно получить из свойств пика.
- Нажать на кнопку рассчитать и полученные значения коэффициента "A" и его неопределённости будут выведены в соответствующих текстовых полях.
- Скопировать эти значения в параметры конфигурации SpectraLine.

**Опционально**:
- Исходные значения загрузки и скорости счёта можно сохранить в csv-файл, например, чтобы обработать позже.
